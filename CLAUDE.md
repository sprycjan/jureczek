## Commands (run in `app/`)
- Run: `flutter run -d <phone> --dart-define-from-file=env/dev.json` — without the define the app shows "Brak tokenu Mapbox". Token: `ACCESS_TOKEN` (public `pk.`) in `env/dev.json` (from `env/dev.example.json`).
- Test: `flutter test --timeout 30s` (macOS has no `timeout`; hanging tests otherwise never fail). `flutter analyze` must stay at 0 issues.
- After drift table changes: `dart run build_runner build`. Never edit `*.g.dart`. After ARB changes: `flutter gen-l10n`.
- Splash art: `python3 -I tool/splash_art.py assets/splash [--preview <dir>] [--sheet <dir> [all|scene,keys] [day,night]]`. Never edit the SVGs in `assets/splash/`. Phone preview with frame timings: `flutter build apk --profile --target-platform android-arm64 -t lib/dev/splash_main.dart` (tap: next period, long press: next scene); it replaces the app on the phone, so install the normal build afterwards.

## Testing on device
- Manual tests on the Huawei P30 (Android 10), never the emulator (too slow). If the phone is disconnected, ask the user.
- Build for the phone with `flutter run -d <phone>` — an emulator APK is x86_64-only and crashes there.
- Judge startup time, and leave on the phone for daily use, only a release build: `flutter build apk --release --target-platform android-arm64 --dart-define-from-file=env/dev.json`, then `adb install -r`. On the P30 `main()` starts at ~170 ms in release and ~640 ms in profile.
- `adb` is not on PATH: `~/Library/Android/sdk/platform-tools/adb`.

## Rules
- Free tiers only — never propose paid APIs (e.g. Google Places). Mapbox Search Box: 500 free sessions/month, billed per `session_token`.
- Look up library docs with Context7 (`ctx7`); training data for Mapbox v3 / Riverpod 3 is unreliable.

## Gotchas
- Splash (v24): parameters live in `SplashConfig`; layers are `Picture`s with palette tokens from `palettes.json`, so colours change per period without new SVGs. On the P30 the raster margin is small: a scene must not exceed Alps (1657 paths, ~45k segments; the generator prints this). `SplashOverlay` must stay the second child of its `Stack`, or its removal rebuilds the home screen. Layers scroll left, so art left of the first frame is never seen in portrait; a far layer must reach below the top of the hills or sky shows through. Adding a module-level colour renumbers tokens in every SVG without changing the art. The first launch after `adb install` has a ~900 ms gap regardless of scene: discard it when measuring.
- Splash start: `SplashStart` loads the scene from `main()` and holds Flutter's first frame until it is ready (1 s cap), so the first visible frame is the scene. Keep `deferFirstFrame`/`allowFirstFrame` paired.
- Never pass `rootBundle` as `SvgAssetLoader(assetBundle:)` in app code: after any `rootBundle.loadString` it holds `Future`s and fails with "object is unsendable" when sent to the SVG isolate. This does not reproduce in `flutter test`, so check on the phone.
- Pin types (v16): a pin is `PinKind` = the green standard pin (`type == null`) or one of 81 `PlaceType`s; `pins.category` stores the key. Type pins are SVGs in `app/assets/place_icons/` generated by `app/tool/place_icons.py` (edit symbols there, never the SVGs); `flutter_svg` drops `feDropShadow`, so `PlacePin`/`renderPlacePinPng` paint the shadow (`PlacePinGeometry`, checked by `place_icons_test`). Only the green pin is PNG (`app/tool/render_pins.py`, tint layers for custom colour).
- Mapbox SDK v3, not v2: `viewport: CameraViewportState`; `map.addInteraction(TapInteraction.onMap / LongTapInteraction.onMap)` instead of listeners; `Position(lng, lat)` (lng first); `PointAnnotation` needs PNG bytes.
- Riverpod 3 pauses providers without listeners. In tests: `container.listen(p, (_, _) {})` → `pumpEventQueue()` → `read(p).requireValue`; `read(p.future)` hangs.
- The drift DB is the single source of truth (`StreamProvider` over `watchAll()`, writes through controllers). Ids are UUID v4.
- Schema changes: bump `schemaVersion`, hand-write `if (from < N)` in `onUpgrade`, and add a migration test that builds the old schema with raw SQL + `PRAGMA user_version` (`test/core/database/app_database_migration_test.dart`). Upgrades from schema < 4 wipe the DB on purpose (v9 reset); real migrations start at 4 → 5. Drift `dateTime()` has 1 s precision — use an int ms column when ordering by recency.
- Archive (v23): the all-pins map reads pins through `_pinsSource` (`activePinsProvider`), never `pinsProvider`, or archived pins come back. `Dismissible` must leave the tree right after `onDismissed`, but drift streams arrive later: the home list uses `_pendingMoves`, and a failed write waits for `endOfFrame` before the card returns.
- Widget tests with drift streams: data arrives outside fake async — `await tester.runAsync(() => Future.delayed(50ms))` then `pump`.
- Never log `ClientException.toString()` — it contains the URL with `access_token`; use `e.message`.
- Flutter 3.41: a `SnackBar` with an action needs `persist: false` or it never closes.
- Keep UI clear of the Mapbox logo/attribution (license requirement).
- Gradle wrapper is pinned to 9.1.0 on purpose (8.14 fails with the bundled Java 25).
